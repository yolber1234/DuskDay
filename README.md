# juego-de-programacion1
DuskDays es un motor 2D en Java puro que nació como proyecto en la UNET junto a un amigo. Construimos desde cero la arquitectura para parsear mapas JSON de Tiled, calcular colisiones por capas y manejar eventos. Es un repositorio vivo: seguiremos metiendo mano al código y optimizando el renderizado pixel art poco a poco.
